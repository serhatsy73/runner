# Sürü Ustası

HTML Canvas ile yazılmış, kalabalık koşu (crowd runner) türünde oynanabilir bir prototip.

## Çalıştırma

`index.html` dosyasını tarayıcıda açmanız yeterli. Kurulum ya da derleme gerekmez.

## Kontroller

- Sağa-sola sürükle (veya ← →): sürüyü yönlendir
- Aşağı sürükle (veya ↓): geniş cephe, iki kapıdan birden geçer
- Yukarı sürükle (veya ↑): ince uzun kol, dar köprüden düşmeden geçer
